Hausdienst-PWA v1

Alle Dateien unverändert zusammen auf einem HTTPS-Host bereitstellen. Dann auf iPhone in Safari öffnen > Teilen > Zum Home-Bildschirm. Android: Chrome > Installieren / Zum Startbildschirm hinzufügen.

Dienstdaten werden lokal im Browser-Speicher des jeweiligen Geräts gespeichert und nicht durch die App hochgeladen. Eine JSON-Datensicherung regelmäßig lokal exportieren. Die App nicht im privaten Browsermodus verwenden. Browserdaten löschen oder App entfernen kann Daten löschen.

ACHTUNG: Ein Webhost liefert Programmcode und kann Zugriffe auf die App protokollieren; außerdem kann der Betreiber den bereitgestellten Code ändern. Deshalb nur vertrauenswürdiges HTTPS-Hosting verwenden, keine Drittanbieter-Skripte oder Analytics hinzufügen. Keine identifizierenden Patientendaten eingeben.

Die alte Windows-Datei hat einen anderen Speicherort: Daten werden nicht automatisch übernommen.
